# Sorting Algorithms Visualizer

An interactive Java-based educational tool designed to visualize the step-by-step execution of fundamental sorting algorithms. This project helps bridge the gap between theoretical computer science concepts and practical application.

## Key Features
* **Real-time Visualization:** Watch algorithms sort an array of bars in real-time using a custom GUI.
* **Supported Algorithms:** 
    * Bubble Sort
    * Insertion Sort
    * Selection Sort
* **Interactive UI:** Built with Java Swing, allowing for responsive user interaction during sorting processes.
* **Customizable Highlighting:** Uses color-coding (red for active elements) to track comparisons and swaps as they occur.

## Prerequisites
* **Environment:** Java Runtime Environment (JRE) 8 or higher.
* **OS:** Compatible with Windows, macOS, and Linux.
* **Development:** JDK 8+ and a Java-compatible IDE.

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mmohibali/Sorting-Visualizer.git
   cd Sorting-Visualizer
2. Compile the application:
  Navigate to the src folder and compile the package:
   ```bash
   cd src
   javac sortingvisualizer/*.java
3. Run the visualizer:
   ```bash
   java sortingvisualizer.SortingVisualizer
   
## Project Overview

This tool provides visual feedback on algorithmic efficiency and logic. It utilizes the SwingWorker class to perform sorting tasks on a background thread, ensuring the GUI remains responsive throughout the visualization.
